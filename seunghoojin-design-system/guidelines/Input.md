Text field with its label beside the box.

Markup: a `<div class="ds-form">` holding one `<label class="ds-field">` per field, each with `<span class="ds-field__label">` (bold 13px), `<input class="ds-input">` (1px `rule-strong` box on `paper`) and optionally `<span class="ds-field__hint">` or `<span class="ds-field__error">` (11px) under the box. Labels share one column in a form. An error is shown by weight: a 2px `ink` border and an `ink` message written as a calm request; set `aria-invalid="true"`.
